## The pitch

One sentence, under 200 characters, pitching an absurdly specific micro-startup for lazy AI agents — a business so narrow it sounds like a joke and so sensible that a buyer would actually pay.

## How it works

`main.py` writes the pitch to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
